# Qué hacer cuando no funciona

## Si no te responden

**Seguimiento único** (a los 3-5 días):
> *"Hola [nombre], quería asegurarme de que llegó mi mensaje. ¿Tuviste chance de ver el análisis? [link]"*

Un solo seguimiento. Si no responden, sigue con otra empresa. No lo tomes personal.

## Si respondieron pero no hubo llamada

Algo faltó. Revisa:
- ¿El link funciona?
- ¿La evidencia era específica a ellos, o genérica?
- ¿El problema que elegiste es realmente prioritario para ellos?
- ¿Había una mini-demo que mostrara trabajo real?

## Si hubo llamada pero no hubo proyecto

Probablemente el timing no era el correcto o la solución no encajó con su prioridad del momento.

**Qué hacer**: Pide feedback directo. *"¿Qué le faltó al plan para que tenga sentido trabajar juntos?"* La respuesta es información para el siguiente intento.

## Herramientas para el proceso completo

| Paso | Herramienta | Para qué |
|------|-------------|----------|
| Encontrar startups | Crunchbase, YC Directory, Latitud | Base de datos de empresas |
| Analizar empresa | ChatGPT + Prompt Maestro | Análisis profundo rápido |
| Analizar competencia | Perplexity | Búsqueda con fuentes verificables |
| Crear el documento | Notion (gratis) | Entrega profesional |
| Crear presentaciones | Gamma (gratis) | Si tu perfil es visual |
| Encontrar emails | Hunter.io (50/mes gratis) | Contacto directo |
| Cobrar en dólares | Wallbit / Wise | Recibir pagos desde Bolivia |
| Revisar inglés escrito | ChatGPT | Antes de mandar cualquier mensaje |

## Mapa de inseguridades rápido

| Inseguridad | Respuesta |
|-------------|-----------|
| "No tengo experiencia" | El PVP crea la experiencia. El documento que haces es tu portafolio. |
| "Soy de Bolivia, nadie me contrata" | Una startup de 10 personas no contrata ubicaciones — contrata soluciones. |
| "No tengo inglés" | Empieza con startups en español. Usa IA para revisar inglés escrito. |
| "¿Y si me ignoran?" | La mayoría lo hará. Planifica 20-40 intentos, no 5. |
| "No sé cómo cobrar" | Wallbit te abre una cuenta en EEUU en 48h. |
| "¿Es legal?" | Sí. Regulariza con NIT cuando escales. |
| "¿Cuánto tarda?" | 2-3 meses si ejecutas consistentemente. |
| "¿Necesito certificaciones?" | No. PVP no pide certificaciones. Pide trabajo real. |
