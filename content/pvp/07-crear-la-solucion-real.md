# Paso 3: Crear la solución real

**Acá demuestras de qué estás hecho. Acá ganas.**

## Cómo elegir QUÉ resolver

Elige UN problema de esta lista:
- Problema que está **perdiendo dinero** (funnel roto, precio mal posicionado)
- Problema que está **perdiendo clientes** (onboarding confuso, falta de retención)
- Problema que está **perdiendo vistas/engagement** (contenido inconsistente)
- Problema que está **frenando el crecimiento** (posicionamiento débil)
- Problema que está **causando fricción al usuario** (UX rota)

**El criterio**: El mejor problema es aquel donde puedes entregar una solución visible, concreta, que ellos puedan implementar en días — no meses.

---

## Tipos de soluciones por perfil

**Marketing** → Plan de contenido 7-14 días con ejemplos reales + 3 piezas listas para publicar

**Diseño** → Rediseño de landing (wireframe/mockup en Figma) o corrección de inconsistencias de UI con antes/después

**Producto / UX** → Mapa de fricción del onboarding + user flow mejorado + lista de quick wins por impacto/esfuerzo

**Community / Contenido** → 5 scripts de videos listos + calendario de contenido con temas, formatos y frecuencia

**Ventas** → Auditoría del funnel + script de llamada con objeciones y respuestas + secuencias de email listas

**Programación** → Prototipo rápido de un feature que identificaste que falta

**Operaciones** → Automatización con Zapier/Make para un flujo específico

---

## Formato de entrega

**Obligatorio**: Tienes que entregar un link, no un archivo adjunto.

Los archivos adjuntos van al spam o no se abren. Un link se ve en segundos.

| Opción | Para qué |
|--------|----------|
| **Notion** (recomendado) | Profesional, limpio, responsivo |
| **Gamma** | Presentaciones estilo pitch deck. Ideal si tu perfil es visual |
| **Miro** | Mapas visuales y flujos. Ideal para producto, UX |
| **PDF (Google Docs)** | Simple, universal. Para cuando no sabes las otras opciones todavía |

---

## Estructura exacta del documento (9 secciones)

1. **Portada** — Logo de la empresa, título, tu nombre + país + área
2. **Resumen** — Máximo 4 líneas. Sin relleno.
3. **Lo que vi** — Screenshots reales, links concretos, datos. Esto genera confianza.
4. **Oportunidad #1** — Qué es, por qué les cuesta, evidencia
5. **Oportunidad #2** — misma estructura
6. **Oportunidad #3** — misma estructura
7. **Mi propuesta** — Plan de 30 días, 3 entregables con nombres y descripción
8. **Mini-demo** — 1-2 piezas de trabajo real (no bocetos)
9. **CTA** — "Si esto te sirve, podemos agendar 15 minutos." No pidas el trabajo. Solo la llamada.
